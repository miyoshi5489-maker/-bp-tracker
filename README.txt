== 洋平トレーニング（旧 BP Tracker）==

ゴルフ体づくり・マラソン・筋トレの「計画」と「記録」を1つにまとめたアプリです。
記録データは今まで通り Supabase（training_logs）に保存されます。

【ページ】
今日     … 今日のメニュー、ラウンド／篠山までの日数、今週の進み具合
ゴルフ   … ジーニールーティン／ゴルトレ Day1〜3／体のチェック（写真付き、できた種目をタップして保存）
マラソン … 篠山（2027/3/7）までの期間、目標ペース、月間距離、土曜ロング走
週間     … 1週間の予定と実績
月間     … カレンダーで予定と実績
記録・履歴・進捗・取込 … 従来の機能

【ファイル】
index.html    画面
app.js        動き（記録・表示）
plan.js       計画（ゴルフ期 → 土台期 → マラソン期）
exercises.js  ゴルフ体づくりの種目データ
img/          種目の写真
app.css       Tailwind CSS でビルドしたスタイル
src/input.css Tailwind の元ファイル

【見た目を変えたとき】
npm install
npm run build:css   ← app.css が作り直されます
