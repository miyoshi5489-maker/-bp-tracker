== BP Tracker PWA — セットアップ手順 ==

このフォルダをそのままWebサーバーに置くだけで動きます。

--------------------------------------------
【無料で一番簡単】Vercelにデプロイする方法
--------------------------------------------
1. https://vercel.com にサインアップ（無料・Googleアカウント可）
2. 「Add New → Project」
3. 「Deploy without Git」→ このフォルダを丸ごとドラッグ＆ドロップ
4. Deployをクリック → URLが発行される（例: bp-tracker.vercel.app）
5. iPhoneのSafariでそのURLを開く
6. 共有ボタン →「ホーム画面に追加」→ 完成！

--------------------------------------------
【ローカルで動作確認する方法（Node.js使用）】
--------------------------------------------
$ cd このフォルダ
$ npx serve .
→ http://localhost:3000 で確認できます

--------------------------------------------
【ファイル構成】
--------------------------------------------
index.html   ← メインアプリ
manifest.json ← PWA設定（アイコン・テーマカラーなど）
sw.js        ← Service Worker（オフライン対応）
icon-192.png ← アプリアイコン（小）
icon-512.png ← アプリアイコン（大）

--------------------------------------------
【注意】
--------------------------------------------
・記録はブラウザのLocalStorageに保存されます
・同じURLにアクセスし続けることで記録が消えません
・ブラウザのキャッシュクリアや「サイトデータを削除」をすると消えるので注意
